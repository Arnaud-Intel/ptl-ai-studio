Let the integrated GPU use more memory

The 30-billion-parameter coding model behind the Page Agent, Code Review and HTML Creator runs on the integrated GPU, which has no memory of its own: it borrows the laptop's. While it writes a page the model needs about 20 GB of it. Windows lets the integrated GPU use only 57% of the memory unless told otherwise: on a 32 GB laptop that is 18 GB, too little, and the Studio greys the model out. At 75% it is 24 GB, which is enough.

Change it in Intel Graphics Software

  1. Open Intel Graphics Software: press the Windows key and type its name. It comes with Intel's graphics driver.
  2. 1 Click Graphics in the menu on the left.
  3. 2 Under General, turn on Shared GPU/NPU Memory Override.
  4. 3 Under it, set Memory Limit to 75: type it in the box on the right, or drag the slider. The figure on the left of the slider shows what that is in GB.
  5. Restart the laptop. The new limit applies only after a restart. Until then the Studio says that the limit was changed and keeps the model greyed out.
  6. Open the Studio again: the notice is gone and the Page Agent opens.

What the setting does

It is a ceiling, not a reservation: memory the GPU is not using stays free for Windows and every other app. At 75% a 32 GB laptop keeps at least 8 GB for the rest. Going much higher leaves Windows short when a large model is loaded, so 75% is the setting to use.

64 GB36 GB: enough48 GB: enough

On a laptop with less than 48 GB the Studio also lets go of the models a demo left loaded as soon as another demo starts, so that two of them never need that memory at once. Bringing one back takes a few seconds.

If it is not there

  • The setting needs an Intel Core Ultra processor of Series 2 or later, and a recent Intel graphics driver (32.0.101.6974 or later) with its Intel Graphics Software. Older versions call it "Shared GPU Memory Override"; it is in the same place.
  • Intel says a limit under 50% is not saved.
  • To undo it, turn the switch off, or set 57 again, and restart.
  • The Studio cannot change the setting for you: Intel's app is the only published way, and it takes a restart.
